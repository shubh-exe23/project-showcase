## Pharmacy Management System *(Team Project)*

### Overview
A full-stack pharmacy management application designed to streamline medicine ordering, authentication, inventory workflows, and disease assistance through an integrated prediction system.

The platform supports both **customers and administrators**, enabling secure medicine management, order handling, analytics, and healthcare assistance through a lightweight AI-powered disease prediction helper.

### Tech Stack
- **Frontend:** React, Vite
- **Backend:** Express.js, Node.js
- **Database:** MySQL
- **Authentication:** JWT, OTP-based login & password reset
- **AI/ML:** Python, Decision Tree Classification
- **Additional Features:** Analytics, Role-based Admin Features

### Key Features
- Customer and Admin interfaces
- Secure authentication using **JWT + OTP verification**
- Password reset flow
- Medicine inventory and ordering system
- Admin dashboard and analytics
- Automated MySQL schema creation and seed data
- Disease prediction support through Python integration

### System Architecture
```text
React Frontend
        ↓
Express API Server
        ↓
MySQL Database
        ↓
Python Disease Prediction Helper
```

### My Contribution
I was responsible for building the **AI-powered disease prediction module** of the system.

My work involved:

- Developing the disease prediction logic using the **Decision Tree Classification algorithm**
- Working on symptom-based disease classification
- Integrating the prediction workflow into the backend system
- Assisting in connecting the Python prediction helper with the main application pipeline

This component was designed to provide preliminary disease suggestions based on user symptoms, supporting the pharmacy experience with an intelligent helper system.

### Key Learnings
- Full-stack application architecture
- API-based integration between Node.js and Python
- Database design using MySQL
- Authentication workflows using JWT and OTP systems
- Practical implementation of **Decision Tree Classification** in a real-world project
- Collaborative software development in a team environment
